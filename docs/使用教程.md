## 1. 产品介绍

### 1.1 这是什么

**择言 SelTalk** 是一款 Windows 桌面 AI 聊天助手。它采用「**被动触发**」模式——你在任意应用中复制一段文本，按下热键，SelTalk 会读取剪贴板内容、调用大语言模型（LLM）生成多条候选回复，在一个轻量悬浮窗中供你挑选，选中后以**逐字模拟输入**的方式写入当前光标位置。

整个流程无需切换窗口、无需手动粘贴，适合在聊天软件、文档编辑器、客服系统等场景下快速组织回复。

### 1.2 工作流程一览

```
① 选中文字 → Ctrl+C 复制
        ↓
② 按下热键（默认 Ctrl+Shift+Space，可自定义）
        ↓
③ SelTalk 读取剪贴板 → 清洗 → 黑名单脱敏 → 调用 LLM
        ↓
④ 悬浮窗弹出，显示原文 + 多条候选回复
        ↓
⑤ ↑↓ 选择 → Tab 确认
        ↓
⑥ SelTalk 在原光标位置逐字输入选中的回复
```

### 1.3 技术特性

| 特性 | 说明 |
|------|------|
| 被动热键触发 | 不抢占焦点，仅在按下热键时工作 |
| 剪贴板安全 | 读取后**立即原样还原**，不破坏你已复制的内容 |
| 黑名单脱敏 | 手机号/身份证/邮箱等在送入 LLM 前替换为 `***` |
| 词库注入 | 可将常用术语通过 `{{words}}` 变量注入提示词 |
| 词频统计 | 自动统计你选用的候选词汇，可视化高频词云 |
| 任务锁 + 看门狗 | 防止重复触发；卡死 60 秒自动恢复 |
| 系统托盘 | 可暂停/恢复热键，避免与其他软件冲突 |
| 开机自启 | 可选，系统启动时自动运行 |

## 2. 安装与卸载

### 2.1 方式一：安装包（推荐普通用户）

1. 获取安装包 `SelTalk_x.x.x_x64-setup.exe`（NSIS 安装程序）。
2. 双击运行，按向导选择安装目录，点击「安装」。
3. 安装完成后会自动创建桌面快捷方式与开始菜单项。
4. 首次启动若弹出 SmartScreen 提示，点击「更多信息 → 仍要运行」（应用未签名所致，属正常现象）。

> 📝 **界面示意**：安装完成后，桌面会出现「择言 SelTalk」图标。启动后**管理面板**窗口打开，同时在系统托盘（右下角）出现应用图标。

### 2.2 方式二：从源码构建（适合开发者）

需要预先安装：[Node.js](https://nodejs.org/) 18+、[pnpm](https://pnpm.io/)、[Rust](https://rustup.rs/) 工具链、WebView2 运行时。

```powershell
# 1. 克隆项目并进入目录
cd D:\vibecoding\择言（SelTalk）

# 2. 安装前端依赖
pnpm install

# 3. 开发模式运行（热重载）
pnpm tauri dev

# 4. 打包发布版本（生成安装包）
pnpm tauri build
# 产物位于 src-tauri\target\release\bundle\nsis\
```

### 2.3 数据存储位置

| 类型 | 路径 |
|------|------|
| 配置与词库数据库 | `%APPDATA%\com.seltalk.app\seltalk.db` |
| 运行日志 | `%LOCALAPPDATA%\com.seltalk.app\logs\` |

> 卸载时数据库与日志**不会**被自动删除。如需彻底清除，手动删除上述两个目录即可。

### 2.4 卸载

- **安装包用户**：通过「设置 → 应用 → 已安装的应用」找到 SelTalk 并卸载，或运行安装目录下的卸载程序。
- **源码用户**：关闭进程后删除项目目录与上述数据目录即可。

## 3. 首次配置

首次启动后，需完成两步配置才能正常使用：**配置 LLM** 和 **设置热键**。

### 3.1 配置 LLM（必填）

管理面板默认打开「LLM 配置」页。SelTalk 兼容 OpenAI 接口格式，支持任何遵循该规范的服务商（OpenAI、DeepSeek、Moonshot、本地 Ollama 等）。

**界面布局**：

```
┌─ LLM 配置 ────────────────────────────────────┐
│ 接口地址  [ https://api.openai.com         ]  │
│ API Key   [ sk-...（点击眼睛图标查看）      ]  │
│ 模型名称  [ gpt-4o-mini                     ]  │
│ 温度      [ 0.8 ]   范围 0~2                 │
│ 最大长度  [ 1024 ]  范围 1~8192              │
│                                                  │
│          [ 保存 ]   [ 测试连通性 ]            │
│          ✅ 成功  连接成功（856ms）            │
└──────────────────────────────────────────────────┘
```

**操作步骤**：

1. **接口地址**：填写服务商基地址，**不要**带 `/v1/chat/completions` 后缀，仅填到根域名即可。
   - OpenAI：`https://api.openai.com`
   - DeepSeek：`https://api.deepseek.com`
   - 本地 Ollama：`http://localhost:11434`
2. **API Key**：填入服务商提供的密钥（`sk-...`），输入框默认隐藏，可点击右侧眼睛图标查看。
3. **模型名称**：填写模型标识，如 `gpt-4o-mini`、`deepseek-chat`。
4. **温度**：控制回复随机性，`0` 严谨保守，`2` 发散跳跃，日常回复建议 `0.6~0.9`。
5. **最大长度**：单次生成最大 token 数，`1024` 约等于 500~700 汉字。
6. 点击「**保存**」，再点「**测试连通性**」。出现绿色「成功」标签即配置完成。

> ⚠️ **常见错误**：若测试报错，请检查接口地址是否多了 `/v1/`（SelTalk 会自动拼接），以及 API Key 是否有效。

### 3.2 设置热键（必填）

切换到「设置」页，找到「全局热键」卡片。

1. 点击「**录入**」按钮，输入框显示「请按下组合键…」。
2. 按下你想要的组合键，例如 `Alt+X`。输入框自动填入。
3. 点击「**保存并注册**」，提示「热键已保存并注册」即生效。

> 🚫 **冲突保护**：SelTalk 已内置系统保留键黑名单，**禁止注册** `Ctrl+C`、`Ctrl+V`、`Ctrl+X`、`Ctrl+Z`、`Ctrl+A`、`Ctrl+S`、`Alt+F4`、`Alt+Tab` 等。若录入这些组合，会即时弹出冲突提示。请使用 `Alt+字母` 或 `Ctrl+Shift+字母` 等多修饰键组合。

> 💡 **录入小技巧**：录入过程中按 `Esc` 可取消并恢复原热键值。

### 3.3 推荐初始配置

| 项 | 推荐值 | 说明 |
|----|--------|------|
| 热键 | `Alt+X` 或 `Ctrl+Shift+Space` | 不与系统/常用软件冲突 |
| 候选条数 | 3 | 数量越多等待越久 |
| 最小延迟 | 30 ms | 逐字输入下限 |
| 最大延迟 | 120 ms | 逐字输入上限 |
| 悬浮窗尺寸 | 420×360 | 默认值，可后续拖拽调整 |

## 4. 核心功能操作指南

### 4.1 主流程：复制 → 触发 → 选择 → 输入

这是 SelTalk 最核心的操作，掌握此流程即可上手。

**步骤演示**（以微信聊天为例）：

1. 在聊天窗口中，用鼠标选中对方发来的一句话。
2. 按 `Ctrl+C` 复制到剪贴板。
3. 按 `Alt+X`（你设置的热键）触发 SelTalk。
4. 稍候，**悬浮窗**在屏幕中弹出，显示：
   - 顶部「原文」框：你复制的文本（已脱敏）。
   - 下方候选列表：AI 生成的多条回复，每条前有编号。
5. 用 `↑` `↓` 键切换选中项（蓝底高亮），或鼠标单击选中。
6. 按 `Tab` 确认（或鼠标双击），悬浮窗消失。
7. SelTalk 在原光标位置**逐字输入**选中的回复，如同你亲手打字。

**悬浮窗界面示意**：

```
┌─ 择言 ────────────────────── 📌 ✕ ┐
│ ┌ 原文 ────────────────────────┐ │
│ │ 你明天有空吗？想约你吃饭     │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 1  好呀，明天什么时间方便？  │ │  ← 蓝底高亮 = 当前选中
│ │ 2  可以啊，你想去哪里吃？    │ │
│ │ 3  明天可能有点忙，后天呢？  │ │
│ └──────────────────────────────┘ │
│      ↑↓ 切换 · Tab 确认 · ESC 关闭 │
└────────────────────────────────────┘
```

**悬浮窗操作速查表**：

| 操作 | 按键/鼠标 | 说明 |
|------|-----------|------|
| 切换候选 | `↑` / `↓` | 循环选择，到末尾回到开头 |
| 选中候选 | 鼠标单击 | 仅高亮，不输入 |
| 确认输入 | `Tab` 或双击 | 逐字输入到光标处 |
| 关闭取消 | `Esc` 或 ✕ | 隐藏悬浮窗，不输入 |
| 切换置顶 | 📌/📍 按钮 | 置顶时图标为 📌 |
| 移动窗口 | 拖拽顶部栏 | 位置自动记忆 |
| 中断输入 | `Esc` | 输入过程中按可中止 |

### 4.2 词库管理

词库用于存放你常用的术语、口头禅、专业词汇，通过 `{{words}}` 变量注入提示词，让 AI 回复更贴合你的风格。

**路径**：管理面板 → 侧边栏「词库管理」

**功能**：

- **新增词条**：输入「词语」+「分类」（如 `摸鱼` / `日常`），点击添加。
- **批量导入**：点击「批量导入」，在文本框粘贴 JSON 数组：
  ```json
  [
    { "word": "收到", "category": "职场" },
    { "word": "安排上了", "category": "日常" },
    { "word": "代码已提交", "category": "开发" }
  ]
  ```
  重复词条自动跳过，导入后显示「成功 X 条，跳过 Y 条」。
- **搜索与筛选**：顶部搜索框按关键词过滤，下拉框按分类过滤。
- **启禁用**：每条词条右侧开关，禁用后不参与 `{{words}}` 注入。
- **导出**：点击「导出 JSON」备份全部词库。

### 4.3 Prompt 模板

Prompt 模板决定 AI 如何理解你的需求。你可以创建多套模板应对不同场景。

**路径**：侧边栏「Prompt 模板」

**模板语法**：用 `{{变量名}}` 占位，运行时自动替换：

| 变量 | 含义 | 示例 |
|------|------|------|
| `{{text}}` | 你复制的原文（已脱敏） | 必填，主输入 |
| `{{words}}` | 启用的词库词条（顿号连接） | 可选，风格引导 |

**示例模板**：

```
你是一位善于接话的朋友。请根据对方的话，用轻松自然的口吻给出 {{count}} 条简短回复（每条不超过20字）。
可用词汇参考：{{words}}

对方说：{{text}}
```

**操作**：

1. 点击「新建模板」，填入名称和模板内容。
2. 右侧「变量预览」实时展示替换后的效果，便于调试。
3. 点击「设为默认」，该模板即为主链路使用的提示词。
4. 可创建多个模板（如「正式回复」「搞笑接话」「客服话术」），按需切换默认。

### 4.4 文本过滤黑名单

黑名单用于在文本送入 LLM **之前**对敏感信息脱敏，保护隐私。

**路径**：设置 → 「文本过滤黑名单」卡片

**默认规则**（已内置）：

| 类型 | 正则表达式 | 替换为 |
|------|-----------|--------|
| 手机号 | `1[3-9]\d{9}` | `***` |
| 身份证 | `\d{17}[\dXx]` | `***` |
| 邮箱 | `[\w.+-]+@[\w-]+\.[\w.-]+` | `***` |

**操作**：

- 「添加规则」：新增一行，输入正则。
- 「删除」：移除某条规则。
- 「恢复默认」：重置为内置三条。
- 「保存黑名单」：生效。命中规则的片段在「原文」框中显示为 `***`。

> 💡 正则采用 Rust `regex` 语法，不支持回溯引用，但常用功能齐全。

### 4.5 高频词云

SelTalk 会自动统计你**选中并输入**的候选回复中的高频词，帮助你发现常用表达。

**路径**：侧边栏「高频词云」

**界面**：

- 顶部统计卡片：不同词语数、累计使用次数。
- 中部词云图：词语越大表示使用越频繁（基于 ECharts）。
- 「重置」按钮：清空全部词频记录。

> 📝 词频仅在你通过悬浮窗确认输入后累加，取消或关闭不计入。中文按词分割，自动过滤单字与停用词。

### 4.6 系统托盘

应用启动后，系统托盘（右下角）会出现 SelTalk 图标。

**右键菜单**：

| 菜单项 | 功能 |
|--------|------|
| 显示管理面板 | 打开/聚焦管理面板窗口 |
| 暂停热键 / 恢复热键 | 临时停用全局热键（避免打游戏/演示时误触） |
| 退出 | 完全退出应用 |

- **左键单击**托盘图标：显示/隐藏管理面板。
- 暂停热键后，托盘提示文字变为「择言 SelTalk（热键已暂停）」。

### 4.7 设置项详解

**路径**：侧边栏「设置」，完整配置一览：

| 分类 | 配置项 | 范围/默认值 | 说明 |
|------|--------|------------|------|
| 全局热键 | 触发热键 | 默认 `Ctrl+Shift+Space` | 录入后点「保存并注册」 |
| 输入行为 | 候选条数 | 1~10，默认 3 | AI 一次返回的候选数 |
| 输入行为 | 最小延迟 | 0~1000 ms，默认 30 | 逐字输入间隔下限 |
| 输入行为 | 最大延迟 | 0~2000 ms，默认 120 | 逐字输入间隔上限 |
| 悬浮窗 | 默认宽度 | 320~800，默认 420 | 首次弹出尺寸 |
| 悬浮窗 | 默认高度 | 240~600，默认 360 | 首次弹出尺寸 |
| 悬浮窗 | 默认置顶 | 开/关，默认开 | 是否总在最前 |
| 悬浮窗 | 样式预设 | 紧凑/标准/宽松 | 字号与间距 |
| 安全 | 黑名单 | 正则列表 | 见 4.4 |
| 系统 | 开机自启 | 开/关，默认关 | 系统启动自动运行 |

> 延迟范围说明：每打一个字，在 `[最小延迟, 最大延迟]` 区间随机取值，模拟真人打字节奏，避免被识别为机器输入。

## 5. 常见使用场景示例

### 场景一：日常聊天秒回

**目标**：朋友发来消息，快速给个自然回复。

1. 选中朋友的消息「你周末干嘛去」。
2. `Ctrl+C` 复制。
3. 按 `Alt+X`，悬浮窗弹出 3 条候选：
   - 1 打算去爬山，要一起吗？
   - 2 在家躺平，你呢？
   - 3 约了朋友看电影 🎬
4. `↓` 选到第 2 条，`Tab` 确认，自动输入到聊天框。

### 场景二：客服工单回复

**目标**：统一客服话术，提升效率。

1. 在「Prompt 模板」创建模板：
   ```
   你是专业客服。请针对客户问题，给出 3 条礼貌、专业的回复，每条不超过50字。
   严禁承诺具体赔偿金额。
   客户问题：{{text}}
   ```
   设为默认。
2. 在「词库管理」导入客服术语（`您好`、`非常抱歉`、`已为您加急`）。
3. 选中客户工单内容，复制 → 按热键 → 选候选 → Tab 输入。
4. 手机号、邮箱会被自动脱敏为 `***`，不外泄。

### 场景三：写作润色

**目标**：把口语化草稿改成书面表达。

1. 创建「润色」模板：
   ```
   请将下面这段口语化文字润色为书面、简洁的表达，保留原意，给出 3 个版本：
   {{text}}
   ```
2. 选中你的草稿，复制 → 按热键 → 在 3 个润色版本中挑选 → Tab 输入到文档。

### 场景四：多语言翻译接话

**目标**：对方发英文，你需要中文回复思路。

1. 模板设为：
   ```
   对方用英文说：{{text}}
   请理解其含义，用中文给出 3 条可回复的建议（可中英混合）。
   ```
2. 复制英文消息 → 热键 → 选中文建议 → 输入。

### 场景五：临时暂停避免误触

**目标**：打游戏或做演示时，不想热键干扰。

1. 右键托盘图标 → 「暂停热键」。
2. 此时按 `Alt+X` 不会触发任何操作。
3. 完事后右键托盘 → 「恢复热键」。

## 6. 注意事项

### 6.1 热键选择

- ✅ **推荐**：`Alt+字母`、`Ctrl+Shift+字母`、`Ctrl+Alt+字母`。
- 🚫 **禁止**：`Ctrl+单字母`（如 `Ctrl+C/V/X`）会被系统拦截，SelTalk 已内置黑名单。
- ⚠️ 避免与输入法、截图软件、录屏软件的热键重复。

### 6.2 剪贴板安全

- SelTalk 读取剪贴板后会**立即原样还原**，你之前复制的内容不会丢失。
- 但在触发的**瞬间**（毫秒级）请勿同时操作剪贴板，避免竞态。
- 若还原异常，日志会出现「剪贴板还原失败」，此时重新复制一次即可。

### 6.3 LLM 费用与隐私

- SelTalk 本身不收费，但调用 LLM 接口会产生服务商侧费用。
- **黑名单脱敏**仅在送入 LLM 前生效，原文仍会发送给服务商，请勿在敏感场景关闭黑名单。
- API Key 存储在本地数据库，不上传任何第三方服务器（仅发送给配置的 LLM 接口）。

### 6.4 逐字输入

- 输入过程中，光标**必须停留在目标窗口**。若切换窗口，输入可能写到错误位置。
- 输入中按 `Esc` 可中断。
- 若目标窗口是管理员权限应用，而 SelTalk 以普通权限运行，输入可能失效——请用同等权限启动 SelTalk。

### 6.5 性能建议

- 候选条数不宜过大（建议 ≤5），否则 LLM 响应变慢。
- 网络不佳时，LLM 请求最长等待 30 秒超时。
- 任务锁卡死时，看门狗会在 60 秒后自动恢复，无需手动重启。

## 7. 故障排除

### 7.1 按热键无反应

| 可能原因 | 排查方法 | 解决方案 |
|----------|----------|----------|
| 热键被设成系统键 | 打开设置页查看当前热键 | 改为 `Alt+X` 等非冲突键 |
| 热键已暂停 | 看托盘提示是否「热键已暂停」 | 右键托盘「恢复热键」 |
| 任务锁卡死 | 查日志是否有「任务忙，忽略重复触发」 | 等待 60 秒看门狗恢复，或重启应用 |
| 热键与其他软件冲突 | 退出其他全局热键软件测试 | 更换热键组合 |
| 剪贴板为空 | 复制后查看日志「剪贴板文本为空」 | 确认复制成功再触发 |

### 7.2 复制功能（Ctrl+C）失效

这是**最典型**的问题，根因几乎总是**热键被设成了 Ctrl+C**：

1. **立即检查**：打开设置页，看热键是否显示 `Ctrl+C`（或任何 `Ctrl+单字母`）。
2. **修正**：点击「录入」，按 `Alt+X`，点「保存并注册」。
3. **验证**：在记事本里选中文字按 `Ctrl+C`，粘贴确认能复制。

> ℹ️ 新版本已加入黑名单，无法再录入 `Ctrl+C`。若使用旧版本，升级后即可。

**若热键不是 Ctrl+C 但复制仍失效**，按系统层面排查：
- 键盘：在多个应用测试 Ctrl+C，若全局失效则检查键盘硬件。
- 剪贴板服务：`Win+R` 输入 `services.msc`，查找「Clipboard User Service」确认运行中。
- 远程桌面：RDP 会话中剪贴板重定向可能被禁用，检查本地资源设置。

### 7.3 LLM 连接失败

| 错误现象 | 可能原因 | 解决 |
|----------|----------|------|
| 连接超时（>30s） | 网络不通/服务商慢 | 检查网络；本地模型确认已启动 |
| 401 未授权 | API Key 错误 | 重新填写正确的 Key |
| 404 路径不对 | 接口地址带了 `/v1/` | 仅填根域名，如 `https://api.openai.com` |
| 400 模型不存在 | 模型名称拼写错 | 核对服务商模型列表 |
| SSL 证书错误 | 本地 Ollama 自签证书 | 接口地址用 `http://` 而非 `https://` |

排查命令（在设置页点「测试连通性」看返回，或查日志）：

```powershell
# 手动测试接口可达性（替换为你的地址）
curl https://api.openai.com/v1/models -H "Authorization: Bearer sk-你的Key"
```

### 7.4 候选回复质量差

- **温度过低**（接近 0）：回复刻板，调高到 `0.8`。
- **温度过高**（接近 2）：回复跑题，调低到 `0.7`。
- **未配置词库**：AI 不知道你的风格，去「词库管理」添加常用语。
- **Prompt 模板太简陋**：在模板中明确角色、字数、语气要求。

### 7.5 逐字输入写到错误位置

- 确认触发热键时，**目标输入框拥有焦点**。
- 悬浮窗弹出后，**不要点击其他窗口**，直接选候选。
- 输入过程中，SelTalk 会校验焦点窗口句柄，若漂移会中止并提示。

### 7.6 查看日志

日志位于 `%LOCALAPPDATA%\com.seltalk.app\logs\`，按日期命名，默认保留 7 天。

```powershell
# 快速打开日志目录
explorer "$env:LOCALAPPDATA\com.seltalk.app\logs"
```

关键日志关键词速查：

| 关键词 | 含义 |
|--------|------|
| `热键已注册` | 启动时热键注册成功 |
| `热键触发，前台窗口` | 热键被按下，记录了目标窗口 |
| `剪贴板文本为空，忽略本次触发` | 复制失败或剪贴板无文本 |
| `黑名单命中，已对敏感片段脱敏` | 脱敏正常工作 |
| `LLM 生成失败` | LLM 调用出错，看后续详情 |
| `任务锁卡死` | 看门狗即将强制释放 |
| `逐字输入完成` | 主流程成功结束 |

### 7.7 重置应用

若配置混乱无法恢复，可重置为初始状态：

1. 完全退出应用（托盘右键 → 退出）。
2. 删除数据目录：
   ```powershell
   Remove-Item "$env:APPDATA\com.seltalk.app\seltalk.db" -Force
   ```
3. 重新启动应用，所有配置回到默认值（需重新配置 LLM 与热键）。
