## 三、端到端验收步骤（手动）

启动：`pnpm tauri dev` → 托盘左键打开管理面板。

### 1. 词库 CRUD + 搜索 + 启禁用

1. 进入「词库管理」页 → 点击「新增词条」→ 输入「你好」/ 分类「问候」→ 保存。
2. 重复新增「在的」（问候）、「再见」（告别）、「好的」（问候）。
3. 搜索框输入「你」→ 列表仅剩「你好」。
4. 分类下拉选「问候」→ 列表显示 3 条问候词条。
5. 切换某词条「启用」开关 → 关闭 → 勾选「仅启用」→ 该词条不出现。
6. 点击某词条「编辑」→ 改名 → 保存 → 列表更新。
7. 点击「删除」→ 确认 → 列表移除。

**预期**：CRUD/搜索/分类筛选/启禁用均生效，分类下拉随分类变化刷新。

### 2. 批量导入 + 导出回环

1. 点击「批量导入」→ 粘贴以下 JSON：
   ```json
   [{"word":"早","category":"问候"},{"word":"晚安","category":"告别"},{"word":"你好","category":"问候"}]
   ```
2. 点击「导入」→ 提示「成功 2，跳过 1（你好重复），错误 0」。
3. 点击「导出 JSON」→ 浏览器下载 `seltalk_words.json`。
4. 清空词库后再次「批量导入」该 JSON → 全部导入成功（回环验证）。

**预期**：批量导入 100 条无错；导出 JSON 可回导。

### 3. Prompt 模板 + 变量渲染预览

1. 进入「Prompt 模板」页 → 「新建模板」。
2. 模板内容输入：
   ```
   生成 {{n}} 条回复。对话：{{origin}}。参考词：{{words}}
   ```
3. 展开底部「变量渲染预览」→ 自动出现 n / origin / words 三个输入框（已填默认示例值）。
4. 点击「渲染预览」→ 显示替换后的完整文本，与模板变量一致。
5. 保存模板 → 设为默认。

**预期**：变量提取与渲染预览结果与实际 LLM 请求体一致。

### 4. 黑名单过滤

1. 进入「设置」→「文本过滤黑名单」→ 默认显示 3 条规则（手机号/身份证/邮箱）。
2. 保存黑名单。
3. 复制文本 `我的手机是13812345678，邮箱test@x.com` → 触发热键。
4. 悬浮窗「原文」区显示 `我的手机是***，邮箱***`（敏感片段已脱敏）。

**预期**：黑名单正则命中后过滤再送 LLM，原文回显也为脱敏后文本。

### 5. 词库变量注入主链路

1. 词库中新增并启用「在的」「好的」。
2. 复制对话文本 `在吗` → 触发热键。
3. 日志中出现「生成 N 条候选」，LLM 请求体 prompt 含「在的、好的」。

**预期**：启用词库通过 `{{words}}` 注入 Prompt 模板。

### 6. 悬浮窗样式预设

1. 设置页「样式预设」选「紧凑」→ 提示已保存。
2. 触发热键呼出悬浮窗 → 候选字号变小、间距收紧。
3. 切换「宽松」→ 再次呼出 → 字号变大、间距放宽。
4. 重启应用 → 预设保持上次选择。

**预期**：样式预设切换即时生效并持久化。
