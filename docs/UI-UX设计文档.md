## 一、设计总览

### 1.1 双窗口架构

创意输入法由两个独立窗口组成，分别承载不同交互场景：

| 窗口类型     | 形态               | 主要职责                                   | 触发方式                         |
| ------------ | ------------------ | ------------------------------------------ | -------------------------------- |
| 悬浮候选窗   | 无边框、透明、置顶、**不抢焦点（WS_EX_NOACTIVATE）** | 显示 AI 候选回复、刷新、确认输入            | 微信/QQ 选中文本时自动弹出       |
| 管理面板     | 标准窗口、可缩放   | 词库/Prompt/LLM/词云/知识库/设置 全功能管理 | 双击托盘图标、托盘菜单"打开面板" |

**架构特点**：
- 两个窗口独立渲染、互不阻塞；
- 管理面板关闭不影响前台悬浮窗监听；
- 共享同一 Pinia 状态树与 Rust 后端 API（通过 Tauri commands 调用）；
- **Tauri v2 原生多窗口方案承载**（`WebviewWindowBuilder` 创建独立窗口，悬浮窗额外设置 `WS_EX_NOACTIVATE` 扩展样式）。

### 1.2 设计原则

1. **极简被动**：悬浮窗仅显示必要信息，无主动弹窗打扰；
2. **键盘优先**：悬浮窗全程键盘操作，方向键切换、Tab 确认、ESC 中断；
3. **可视化配置**：所有可配置项均在管理面板可视化操作，无需修改代码；
4. **数据驱动**：词云、统计图表实时反映用户习惯与采纳数据；
5. **一致性**：双窗口共用同一设计系统（颜色、字体、图标、间距）；
6. **零 Emoji**：所有图标统一使用 Iconfont SVG 矢量图标，禁止任何 Emoji 符号。

## 三、悬浮候选窗设计

### 3.1 设计决策

采用 **方案 C · 极简文本式**：无边框透明背景，纯文本候选，键盘驱动，极致贴合真人操作习惯。

### 3.2 整体布局

```
┌─────────────────────────────────────┐
│  AI 思考中...                       │  ← 占位态（1-3 秒）
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│  ▸ 好的，稍后处理                   │  ← 候选 1（高亮）
│    收到，马上看看                   │  ← 候选 2
│    好的，我先看看再回复             │  ← 候选 3
│  ─────────────────────────────────  │
│  ↑↓ 切换  · Tab 确认 · ESC 关闭 · ↻ │  ← 操作提示行
└─────────────────────────────────────┘
```

### 3.3 视觉规范

| 元素         | 规格                                                   |
| ------------ | ------------------------------------------------------ |
| 窗口尺寸     | 宽 320px（自适应文本长度，最大 420px），高度动态       |
| 背景         | `rgba(255,255,255,0.95)` 毛玻璃，暗色 `rgba(30,30,30,0.95)` |
| 边框         | 1px solid `--color-border`，圆角 `--radius-lg`        |
| 阴影         | `--shadow-lg`                                          |
| 内边距       | `--space-3`（上下） `--space-4`（左右）                |
| 候选项间距   | `--space-1`                                            |
| 选中候选     | 背景 `--color-primary-light`，左侧 2px `--color-primary` 竖条 |
| 文本         | 13px，行高 1.6，`--color-text`                         |
| 占位文本     | 13px，`--color-text-muted`，省略号动画                 |
| 操作提示行   | 10px，`--color-text-muted`，上方 1px 分割线            |
| 图标         | 12px，操作提示行的快捷键图标                           |
| 出现位置     | 选中文本右下角偏移 8px（UI Automation 失败时显示在鼠标光标右下角） |
| 出现动画     | fade-in + slide-up 8px，150ms ease-out                 |
| 消失动画     | fade-out 100ms ease-in                                |

### 3.4 状态流转

```
[空闲] ──选中文本──▶ [AI 思考中] ──1-3s──▶ [候选展示] ──Tab──▶ [逐字输入]
                              │                    │
                              │                    └──ESC──▶ [空闲]
                              └──失败/超时──▶ [错误提示] ──3s──▶ [空闲]
```

| 状态         | 显示内容                          | 持续时间       |
| ------------ | --------------------------------- | -------------- |
| AI 思考中    | "AI 思考中..." + 省略号动画       | 1-3 秒         |
| 候选展示     | 3 条候选 + 操作提示               | 等待用户操作   |
| 刷新中       | "重新生成中..." + 省略号动画      | 1-3 秒         |
| 错误提示     | "生成失败：{中文原因}"            | 3 秒后自动关闭 |
| 输入中       | 浮窗隐藏，输入进度条不显示         | 直至完成或中断 |

### 3.5 键盘交互

| 按键         | 行为                                       |
| ------------ | ------------------------------------------ |
| ↑ / ↓        | 切换候选（循环）                           |
| Tab          | 确认当前候选，开始逐字模拟输入             |
| ESC          | 关闭浮窗；输入过程中则中断输入（已输入保留） |
| R / ↻        | 刷新候选                                   |
| 1 / 2 / 3    | 直接选择第 N 条候选                        |

### 3.6 异常场景

| 异常                         | 处理                                          |
| ---------------------------- | --------------------------------------------- |
| UI Automation 失败           | 降级 Ctrl+C，浮窗显示在鼠标光标右下角         |
| LLM 请求超时（>10s）         | 浮窗显示"生成超时，请重试或检查网络"          |
| LLM 返回空候选               | 浮窗显示"暂无合适回复，请刷新或修改文本"      |
| 输入过程中窗口失焦            | 自动中断输入，保留已输入内容                  |
| 同一窗口连续多次选中         | 防抖 500ms，避免重复触发                      |

- 切换时记录用户偏好至 localStorage；

// 主题令牌定义
interface ThemeTokens {
  color: {
    primary: string;
    primaryHover: string;
    primaryLight: string;
    bg: string;
    bgSubtle: string;
    bgHover: string;
    border: string;

    success: string;
    warning: string;
    danger: string;
  };
  space: Record<'1'|'2'|'3'|'4'|'5'|'6'|'8', string>;
  radius: Record<'sm'|'md'|'lg'|'full', string>;
  shadow: Record<'sm'|'md'|'lg', string>;
}

// 浅色主题
const lightTheme: ThemeTokens = { /* ... */ };
// 暗色主题
const darkTheme: ThemeTokens = { /* ... */ };

// 通过 CSS 变量注入
function applyTheme(theme: ThemeTokens) {
  const root = document.documentElement;
  Object.entries(theme.color).forEach(([key, value]) => {
    root.style.setProperty(`--color-${key}`, value);
  });
}
